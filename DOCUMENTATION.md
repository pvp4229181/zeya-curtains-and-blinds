# ZEYA Curtains & Blinds — Project Documentation

Website for ZEYA Curtains & Blinds (Dubai, UAE): custom and motorized curtains and
blinds. The same design ships two ways — a static HTML site and a WordPress theme.
The live site will be a WordPress install on a Hostinger domain.

---

## 1. Technology used

| Layer | Technology |
|---|---|
| Markup | HTML5 (semantic) |
| Styling | CSS3 with custom properties; three files — `style.css`, `animations.css`, `responsive.css` |
| Scripting | Vanilla JavaScript (`main.js`) — navigation, scroll reveals, form validation. No jQuery, React, Bootstrap or Tailwind |
| CMS | WordPress 6.3+ with the custom **ZEYA Curtains & Blinds** theme (PHP 7.4+) |
| Images | WebP with responsive sizes; SVG icon sprite |
| Build tools | Python 3 (Pillow) generators in `tools/`; Node scripts for link and interaction checks |
| Hosting / domain | Hostinger (domain + WordPress hosting) |
| Version control | Git, GitHub: `pvp4229181/zeya-curtains-and-blinds` |
| Static preview | Vercel (serves the `dist/` folder via `vercel.json`) |

### Folder map

```
zeya/
├─ zeya-website/   static site source (open index.html to preview)
├─ dist/           generated deployable static bundle — never edit by hand
├─ zeya-theme/     WordPress theme — this is what goes on Hostinger
└─ tools/          generators and tests (not deployed)
```

- 4 collection pages, 38 product pages, plus Home, About, Products, Process, FAQ,
  Contact, Terms and Review.
- Shared markup (header, footer, logo) is generated by `tools/build_pages.py`.
  After changing it, regenerate with:

```
python tools/build_pages.py     # static site
python tools/build_dist.py      # dist/ bundle
python tools/build_theme.py     # WordPress theme
```

## 2. Deploying on WordPress with Hostinger

### A. Domain and hosting
1. Buy or connect the domain in **Hostinger hPanel → Domains**.
2. Choose a WordPress hosting plan and point the domain to it (Hostinger sets the
   nameservers automatically if the domain is bought there).
3. In hPanel, open **Websites → Add website → WordPress** and install WordPress on
   the domain. Create the admin username and a strong password.
4. Turn on the free SSL certificate (**Security → SSL**) so the site loads over HTTPS.

### B. Install the theme
1. Zip the **contents of** the `zeya-theme/` folder as `zeya-theme.zip`
   (the zip must contain `style.css` at its top level).
2. WordPress admin → **Appearance → Themes → Add New → Upload Theme**, choose the
   zip, click **Install Now**, then **Activate**.
   (Alternative: Hostinger File Manager → upload to `public_html/wp-content/themes/`.)

### C. Create the pages
The theme picks each page's design from its **slug**, so slugs must match exactly.

1. **Pages → Add New**, create one page per slug and publish (content can stay empty —
   the theme supplies it):

   `about`, `products`, `process`, `faq`, `contact`, `terms`, `review`,
   `curtains`, `blinds`, `motorized`, `curtain-accessories`, and one page per
   product, e.g. `product-roman-blinds`, `product-zebra-blinds` (full list: the
   `page-product-*.php` files in `zeya-theme/`).
2. **Settings → Reading → Your homepage displays → A static page**, and choose a
   blank page (e.g. "Home") as **Homepage**. The theme's `front-page.php` renders it.
3. **Settings → Permalinks → Post name**, then Save. This gives clean URLs like
   `yourdomain.com/about`.

### D. Menus and contact details
- **Appearance → Menus**: build the *Primary Navigation* and *Footer Navigation*
  menus and assign them to those locations.
- **Appearance → Customize → ZEYA Contact Details**: fill in the real contact
  information (see section 3).

### E. Launch checklist
- [ ] HTTPS active, and `http://` redirects to `https://`
- [ ] Every page above exists and opens (no 404s)
- [ ] Contact details and form endpoint filled in
- [ ] Settings → General: site title "ZEYA Curtains & Blinds", tagline set
- [ ] Test on a phone and a desktop browser
- [ ] Install an SEO plugin (e.g. Yoast or Rank Math) and a backup plugin

## 3. Using the WordPress admin — in brief

Log in at `https://yourdomain.com/wp-admin`.

| Task | Where |
|---|---|
| Change phone, WhatsApp, email, address, opening hours, social links, Google review link, contact-form endpoint | **Appearance → Customize → ZEYA Contact Details** → Publish |
| Edit navigation menus | **Appearance → Menus** |
| Change the logo | **Appearance → Customize → Site Identity → Logo** (otherwise the built-in ZEYA logo is used) |
| Add or edit a page | **Pages → All Pages** → Edit |
| Replace an image | **Media → Library**, or replace the file in `zeya-theme/assets/images/` and re-upload the theme |
| Site title, tagline, timezone | **Settings → General** |
| Home page and permalinks | **Settings → Reading / Permalinks** |
| Add other admins/editors | **Users → Add New** (give staff the *Editor* role, not *Administrator*) |
| Update WordPress and plugins | **Dashboard → Updates** (do this regularly) |

Notes:
- Leave a contact field empty and the site shows the label only, with no link. Nothing
  is invented for you.
- Page layouts and product copy live in the theme files, not the page editor. To change
  product text or layout, edit the source (`tools/catalog.py`, `tools/page_content.py`),
  rebuild with `python tools/build_theme.py`, and re-upload the theme.
- Contact form: the form posts to the **Contact form endpoint** you set in the
  Customizer (a form service or a handler URL). Until one is set, submissions go nowhere.
- Back up before updating the theme: **hPanel → Backups**, or a backup plugin.

## 4. Updating the site later

1. Edit source files locally, then run the build commands in section 1.
2. Commit and push to GitHub.
3. Re-zip `zeya-theme/` and upload it via **Appearance → Themes → Add New → Upload
   Theme** (WordPress offers to replace the existing version), or upload the changed
   files through Hostinger File Manager.
